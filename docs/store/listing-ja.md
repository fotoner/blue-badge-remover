# Chrome ウェブストア掲載情報 — 日本語

## 商品の詳細

**名前:** Blue Badge Remover

**概要 (132文字以内):**

> X(Twitter)で課金バッジ(有料の青いバッジ)の投稿を非表示にします。フォロー中・ホワイトリスト・保護キーワードのアカウントはそのまま表示。

## 詳細な説明

Blue Badge Remover は、X のタイムラインから課金バッジ(有料の青いバッジ)アカウントの投稿を非表示にし、信頼できる人や関心のある話題はそのまま表示します。

主な機能:

- 課金バッジだけを検出します。金色(組織)・灰色(政府)の認証バッジは非表示にしません。
- フォロー中のアカウントを自動で検出して除外し、フォローページから全リストを一括取得できます。
- ホワイトリストに複数アカウントを一括追加でき、折りたたまれた投稿を展開してそのまま除外に追加できます。
- 内蔵・カスタム・読み込んだフィルターパックのキーワードで、特定の課金バッジ投稿だけを非表示にできます。
- ID・名前・プロフィールに好きな人やジャンル、コミュニティを含むアカウントは保護キーワードで表示したままにできます。
- プロフィール情報をブラウザ内だけで使い、作成から間もない高拡散の課金バッジアカウントを選んで非表示にできます(任意)。
- リツイートと引用ツイートを個別に処理し、タイムライン・リプライ・検索・ブックマーク・リストで動作します。
- ホワイトリスト・カスタムフィルター・保護キーワードを検証済みの JSON で書き出し・読み込みできます。
- 設定と統計はブラウザ内にのみ保存します。分析ツール、外部サーバー、認証トークンの保存はありません。
- 日本語・英語・韓国語に対応し、Chrome、Edge、Firefox、Android 版 Firefox で動作します。

この拡張機能はブラウザの表示だけを変更します。X への投稿、いいね、フォロー、コンテンツの変更は行いません。

ソースコードとサポート: https://github.com/fotoner/blue-badge-remover
