# Blue Badge Remover v1.6.2 패치노트

v1.6.1의 모든 변경 사항에 더해, 타임라인에 큰 빈 공간이 남던 문제를 수정했습니다.

## 수정

- 뒤로가기를 하거나 사진·동영상 보기를 닫은 직후 숨겨진 게시물 자리에 큰 빈 공간이 계속 남던 문제를 수정했습니다. '접어서 표시' 방식에서 안내 영역이 비정상적으로 크게 남던 문제도 함께 수정했습니다

## v1.6.1 변경 사항 요약

- 화이트리스트에 여러 아이디를 한 번에 추가하고 목록을 접을 수 있습니다 (`Ctrl/⌘+Enter`로 추가)
- 대시보드나 팝업을 열어둔 채 바꾼 설정이 되돌아가던 문제, 대시보드 번역 누락, 필터 목록 가져오기 안내를 개선했습니다
- 와일드카드가 많은 필터 팩에서 탭이 멈추던 문제, 숨김 통계 누락, 팔로우 목록 저장 누락을 수정했습니다
