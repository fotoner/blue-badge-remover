# Blue Badge Remover v1.6.0 패치노트

이번 업데이트는 숨기면 안 되는 계정을 더 정확히 보호하고, 필요한 예외를 바로 추가할 수 있도록 다듬었습니다.

## 숨김 정확도 개선

- 트윗 작성자 영역의 파란 뱃지만 확인해 인용 트윗 때문에 일반 계정이 함께 숨겨지는 문제를 줄였습니다
- 팔로우 중인 계정, 본인 트윗, 리포스트, 인용 트윗, 화이트리스트 계정의 예외 처리를 강화했습니다
- 리스트 화면에서도 팔로우 중인 계정을 숨기지 않도록 팔로우 판정을 보강했습니다
- 접힌 트윗을 펼치면 트윗 안에서 작성자를 화이트리스트에 추가하거나 다시 접을 수 있습니다

## 새 필터 설정

- `대시보드 → 필터`에서 **신규 고확산 계정 숨기기**를 따로 켤 수 있습니다. 생성 6개월 이내, 팔로워 1천 명 이상, 팔로잉/팔로워 비율 10% 이하인 파란 뱃지 계정을 숨깁니다
- 이 설정은 키워드 필터와 독립적으로 동작합니다. 둘 다 켜면 두 조건 중 하나만 맞아도 숨깁니다
- `대시보드 → 필터 → 고급 필터 설정`에 **보호 키워드** 입력란을 추가했습니다. 한 줄에 하나씩 입력하면 해당 단어가 아이디, 표시 이름, 소개에 포함된 계정은 숨기지 않습니다
- 보호 키워드는 커스텀 필터 문법이 아니라 별도의 보호 목록입니다

## 화이트리스트와 백업

- 화이트리스트 관리 화면에서 여러 아이디를 줄바꿈, 공백, 쉼표로 구분해 한 번에 추가할 수 있습니다
- 등록된 화이트리스트가 길면 목록을 접어둘 수 있습니다
- 화이트리스트, 커스텀 필터, 보호 키워드를 하나의 JSON 파일로 내보내고 다시 가져올 수 있습니다
- 기존 화이트리스트는 자동으로 정리해 이어서 사용하며, 검색 범위와 커스텀 필터를 포함한 기존 설정도 그대로 유지됩니다

## 기타

- 뒤로가기로 타임라인에 돌아왔을 때 스크롤 위치가 크게 흔들리지 않도록 개선했습니다
- 같은 트윗의 숨김 통계가 중복으로 집계되는 문제를 수정했습니다
- 마일스톤 축하 배너는 기본으로 표시하지 않으며, 원하는 경우 설정에서 켤 수 있습니다
