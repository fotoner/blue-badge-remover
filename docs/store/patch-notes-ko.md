# Blue Badge Remover v1.6.1 패치노트

이번 업데이트는 v1.6.0에서 안내했지만 실제로는 적용되지 않았던 화이트리스트 기능을 바로잡고, 설정·통계·필터의 안정성 문제를 고쳤습니다.

## 화이트리스트

- 화이트리스트 관리 화면에서 여러 아이디를 줄바꿈·공백·쉼표로 구분해 한 번에 추가할 수 있습니다. v1.6.0에서 안내했지만 실제 화면에는 적용되지 않았던 문제를 수정했습니다
- 입력란에서 Enter는 줄바꿈이고, `Ctrl+Enter`(Mac은 `⌘+Enter`)로 추가합니다
- 등록된 계정 목록을 접어둘 수 있습니다
- 접힌 트윗을 펼쳐 작성자를 화이트리스트에 추가한 뒤 '다시 접기' 버튼이 남아, 누르면 다시 숨겨지던 문제를 수정했습니다

## 설정과 백업

- 대시보드나 팝업을 열어둔 채 고급 필터 설정에서 바꾼 설정이 원래대로 되돌아가던 문제를 수정했습니다
- 필터 목록 가져오기는 바꿀 항목 수를 먼저 보여주고 확인을 받으며, 성공·실패 결과를 화면에 표시합니다
- 대시보드를 English·日本語로 볼 때 일부 제목과 버튼이 한국어로 남던 문제를 수정했습니다
- 대시보드를 열어둔 채로도 팔로우 동기화 현황이 바로 갱신됩니다

## 안정성

- 와일드카드(`*`)가 많은 필터 팩을 사용할 때 X 탭이 몇 초씩 멈출 수 있던 문제를 수정했습니다
- 와일드카드 규칙이 여러 줄로 된 프로필 소개에서도 동작합니다
- 숨김 통계 일부가 누락되거나 30일이 아닌 29일만 보관되던 문제를 수정했습니다
- 팔로우 목록 저장이 겹칠 때 일부가 누락될 수 있던 문제를 수정했습니다

## 기타

- 기본 필터 목록을 업데이트했습니다. 기여해 주신 분께 감사드립니다
- Firefox와 Edge에도 최신 버전이 함께 배포되도록 배포 과정을 정비했습니다
