# Blue Badge Remover v1.8.2 패치노트

## 변경

- 팔로우가 리트윗한 파딱도 "파딱 리트윗 숨기기" 설정을 따릅니다. 보려면 이 설정을 끄거나 리트윗한 계정을 화이트리스트에 추가하세요
- 인용의 "트윗 전체 숨기기"는 팔로우가 인용해도, 키워드·신규 고확산 선별 필터를 켜도 트윗 전체를 숨깁니다. 인용 부분만 숨기려면 "인용 부분만 숨기기"를 고르거나 인용한 계정을 화이트리스트에 추가하세요
- 설치·업데이트하기 전부터 열려 있던 X 탭은 새로고침해야 필터가 동작합니다. 이제 팝업에, Chrome·Edge에서는 X 화면에도 새로고침 안내가 뜹니다
- 필터링 범위의 "홈 타임라인"에 추천·팔로잉 탭이 모두 들어간다는 것을 표시합니다

## 수정

- 표시 이름에 "@"가 들어간 계정(예: 「名前@C105」)을 인용하면 인용된 계정을 잘못 읽어, 팔로우·화이트리스트 예외와 셀프 인용 판정이 빗나가던 문제를 수정했습니다
- 팔로우하거나 언팔로우해도 이미 화면에 있는 인용 카드의 숨김 상태가 다른 화면에 다녀오기 전까지 바뀌지 않던 문제를 수정했습니다
