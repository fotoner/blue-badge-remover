# Blue Badge Remover v1.7.0 패치노트

영어·일본어 사용자도 처음부터 자기 언어로 쓸 수 있게 했습니다.

## 변경

- 새로 설치하면 브라우저 언어(한국어·일본어, 그 외는 영어)로 시작합니다. 기존 사용자의 언어 설정은 그대로입니다
- 고급 필터, 화이트리스트, 키워드 수집기, 팝업에 남아 있던 한국어 문구를 모두 번역했습니다
- 화이트리스트 화면을 다른 설정 화면과 같은 디자인으로 정리했습니다
- 쓰지 않던 `api.x.com`·`api.twitter.com` 접근 권한을 없앴습니다. 권한이 줄어드는 변경이라 다시 허용할 필요가 없습니다

## 수정

- 영어·일본어로 설정했을 때 설정 화면을 열면 한국어가 잠깐 보였다가 바뀌던 문제를 수정했습니다
- 휴대폰처럼 좁은 화면에서 고급 필터 화면의 버튼 글자가 두 줄로 쪼개지던 문제를 수정했습니다
