# Blue Badge Remover v1.6.0 패치노트

## 새 기능

- 여러 계정을 한 번에 화이트리스트에 추가하고 긴 목록을 접을 수 있습니다
- 숨겨진 트윗을 펼친 뒤 트윗 안에서 작성자를 화이트리스트에 추가하거나 다시 접을 수 있습니다
- 화이트리스트, 커스텀 필터, 보호 키워드를 검증된 JSON으로 내보내고 가져올 수 있습니다
- 핸들, 표시 이름, 소개에 포함된 키워드로 계정을 보호할 수 있습니다
- 생성 6개월 이내, 팔로워 1천 이상, 팔로잉/팔로워 비율 10% 이하인 신규 고확산 계정을 별도로 숨길 수 있습니다

## 정확도 및 안정성

- 작성자 영역의 파란 뱃지만 판별해 인용 트윗으로 인한 오탐을 줄였습니다
- X API, React fiber, DOM을 함께 활용해 팔로우 감지를 보강하고 리스트 화면에서도 팔로우 예외를 적용합니다
- 리포스트, 인용 트윗, 본인 트윗, 화이트리스트 계정의 예외 처리를 강화했습니다
- 화이트리스트 핸들을 소문자로 정규화하고 기존 데이터도 자동으로 마이그레이션합니다
- 키워드 필터와 신규 고확산 계정 필터가 서로 독립적으로 동작합니다
- 뒤로가기 시 스크롤 높이를 보존하고 숨김 통계 중복 집계를 방지합니다
- 펼친 트윗의 확장 기능 버튼을 X 기본 액션 바 위의 본문 영역에 배치합니다
- 옵저버와 저장 작업의 불필요한 반복을 줄였습니다

## 설정 및 유지보수

- 마일스톤 축하 배너는 기본으로 꺼져 있으며 설정에서 켤 수 있습니다
- 큰 옵션 및 콘텐츠 모듈을 분리하고 사용하지 않는 API 뱃지 캐시를 제거했습니다
- 안전하지 않은 타입, 직접 콘솔 사용, 과도한 파일·함수 크기를 검사하는 ESLint 규칙을 추가했습니다
- Chrome, Firefox, Edge 빌드와 496개 테스트로 검증했습니다
