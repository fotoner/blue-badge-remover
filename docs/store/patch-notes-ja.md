# Blue Badge Remover v1.7.0 パッチノート

英語・日本語のユーザーも、最初から自分の言語で使えるようになりました。

## 変更

- 新しくインストールすると、ブラウザの言語（韓国語・日本語、それ以外は英語）で始まります。既存の言語設定はそのままです
- 高度なフィルター設定、ホワイトリスト、キーワード収集、ポップアップに残っていた韓国語の文言をすべて翻訳しました
- ホワイトリスト画面をほかの設定画面と同じデザインに整えました
- 使っていなかった `api.x.com`・`api.twitter.com` へのアクセス権限を削除しました。権限が減る変更のため、再度の許可は必要ありません

## 修正

- 英語・日本語の設定で設定画面を開いたとき、翻訳前の韓国語が一瞬表示される問題を修正しました
- スマートフォンなどの狭い画面で、高度なフィルター設定のボタンの文字が2行に分かれる問題を修正しました
