# Blue Badge Remover v1.8.2 パッチノート

## 変更

- フォロー中のアカウントがリツイートした課金バッジのツイートも「課金バッジのリツイートを非表示」の設定に従います。表示するには設定をオフにするか、リツイートしたアカウントをホワイトリストに追加してください
- 引用の「ツイート全体を非表示」は、フォロー中のアカウントが引用した場合や、キーワード・新規高拡散の選別フィルターを使っている場合もツイート全体を非表示にします。引用部分だけを隠すには「引用部分のみ非表示」を選ぶか、引用したアカウントをホワイトリストに追加してください
- インストール・更新の前から開いていた X のタブは、再読み込みするまでフィルターが動きません。ポップアップに、Chrome・Edge では X の画面にも再読み込みの案内を表示します
- フィルタ範囲の「ホームタイムライン」に、おすすめ・フォロー中の両方のタブが含まれることを表示します

## 修正

- 表示名に「@」を含むアカウント（例：「名前@C105」）を引用したとき、引用されたアカウントを読み違え、フォロー・ホワイトリストの例外やセルフ引用の判定がずれていた問題を修正しました
- フォローやフォロー解除をしても、すでに表示されている引用カードの非表示状態が、別の画面に移動するまで変わらなかった問題を修正しました
