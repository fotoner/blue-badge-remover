# Blue Badge Remover v1.6.0 パッチノート

## 新機能

- ホワイトリスト管理画面で、改行・空白・カンマで区切った複数のIDをまとめて追加し、登録済みアカウント一覧を折りたためるようになりました
- 非表示ツイートを展開した後、ツイート内から投稿者をホワイトリストに追加したり、再び折りたたんだりできます
- ホワイトリスト、カスタムフィルター、保護キーワードを検証済みJSONとしてエクスポート・インポートできます
- 高度なフィルター設定に「保護キーワード」入力欄を追加しました。キーワードを1行に1つ登録すると、その単語がID・名前・プロフィールに含まれる課金バッジアカウントは非表示にしません
- 作成から6か月以内、フォロワー1,000人以上、フォロー数とフォロワー数の比率が10%以下の新規高拡散アカウントを個別に非表示にできます

## 精度と安定性

- 投稿者欄の青いバッジだけを判定し、引用ツイートによる誤検出を減らしました
- Xがタイムライン表示のために読み込んだ情報と画面状態を組み合わせ、リスト画面を含むフォロー判定を改善しました
- リポスト、引用ツイート、自分のツイート、ホワイトリストアカウントの除外処理を強化しました
- ホワイトリストのハンドルを小文字に正規化し、既存データも自動移行します
- キーワードフィルターと新規高拡散アカウントフィルターがそれぞれ独立して動作します
- 戻る操作時のスクロール高さを維持し、非表示統計の重複集計を防ぎます
- 展開したツイートの操作ボタンを、X標準アクションバーの上にある本文欄へ配置します
- 不要なオブザーバー処理とストレージ書き込みを削減しました

## 設定とメンテナンス

- マイルストーンのお祝いバナーは初期状態で無効になり、設定から有効化できます
- 大きくなったオプション・コンテンツモジュールを分割し、未使用のAPIバッジキャッシュを削除しました
- 安全でない型、直接のコンソール使用、過大なファイル・関数を検査するESLintルールを追加しました
- Chrome、Firefox、Edgeのビルドと502件のテストで検証しました
