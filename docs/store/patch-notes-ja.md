# Blue Badge Remover v1.6.0 パッチノート

今回の更新では、表示しておきたいアカウントの保護を強化し、必要な除外設定を追加しやすくしました。

## 非表示判定の精度向上

- 投稿者欄の青いバッジだけを確認し、引用ポストが原因で通常アカウントまで非表示になるケースを減らしました
- フォロー中のアカウント、自分のポスト、リポスト、引用ポスト、ホワイトリストの除外処理を改善しました
- リスト画面でもフォロー中のアカウントを表示できるよう、フォロー判定を改善しました
- 折りたたまれたポストを展開した後、ポスト内から投稿者をホワイトリストに追加したり、もう一度折りたたんだりできます

## 新しいフィルター設定

- `ダッシュボード → フィルター`で「新規の高拡散アカウントを非表示」を個別に有効化できます。作成6か月以内、フォロワー1,000人以上、フォロー数/フォロワー数が10%以下の青バッジアカウントを非表示にします
- この設定はキーワードフィルターとは独立して動作します。両方を有効にした場合は、どちらか一方の条件に一致すると非表示になります
- `ダッシュボード → フィルター → 高度なフィルター設定`に「保護キーワード」欄を追加しました。1行に1語ずつ入力すると、その語がID、表示名、プロフィールに含まれるアカウントは非表示にしません
- 保護キーワードはカスタムフィルターの新しい構文ではなく、独立した保護リストです

## ホワイトリストとバックアップ

- ホワイトリスト画面で、改行・空白・カンマで区切った複数のIDをまとめて追加できます
- 登録済みのホワイトリストが長い場合は、一覧を折りたためます
- ホワイトリスト、カスタムフィルター、保護キーワードを1つのJSONファイルに書き出し、復元できます
- 既存のホワイトリストは自動で整理して引き継ぎ、検索範囲やカスタムフィルターなどの保存済み設定もそのまま維持します

## その他の改善

- ブラウザの「戻る」でタイムラインに戻ったとき、大きくスクロール位置がずれる問題を軽減しました
- 同じ非表示ポストが統計に重複して記録される問題を修正しました
- マイルストーンのお祝いバナーは初期状態で表示せず、必要な場合のみ設定から有効化できます
