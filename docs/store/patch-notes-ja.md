# Blue Badge Remover v1.6.2 パッチノート

v1.6.1のすべての変更に加えて、タイムラインに大きな空白が残る問題を修正しました。

## 修正

- 「戻る」や写真・動画の表示を閉じた直後に、非表示にしたポストの位置に大きな空白が残り続ける問題を修正しました。「折りたたみ表示」で案内欄が異常に大きく残る問題もあわせて修正しました

## v1.6.1の変更点（要約）

- ホワイトリストに複数のIDをまとめて追加し、一覧を折りたためます（`Ctrl/⌘+Enter`で追加）
- ダッシュボードやポップアップを開いたまま変更した設定が元に戻る問題、ダッシュボードの翻訳漏れを修正し、フィルターリストの読み込み時の案内を改善しました
- ワイルドカードの多いフィルターパックでタブが固まる問題、非表示統計の欠落、フォローリストの保存漏れを修正しました
