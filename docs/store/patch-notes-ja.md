# Blue Badge Remover v1.6.1 パッチノート

今回の更新では、v1.6.0で案内したものの実際には反映されていなかったホワイトリスト機能を修正し、設定・統計・フィルターの安定性の問題を解決しました。

## ホワイトリスト

- ホワイトリスト画面で、改行・空白・カンマで区切った複数のIDをまとめて追加できます。v1.6.0で案内したものの、実際の画面には反映されていなかった問題を修正しました
- 入力欄ではEnterで改行し、`Ctrl+Enter`（Macは`⌘+Enter`）で追加します
- 登録済みアカウントの一覧を折りたためます
- 折りたたまれたポストを展開して投稿者をホワイトリストに追加した後も「もう一度折りたたむ」ボタンが残り、押すと再び非表示になる問題を修正しました

## 設定とバックアップ

- ダッシュボードやポップアップを開いたまま高度なフィルター設定で変更した設定が元に戻る問題を修正しました
- フィルターリストの読み込み時に、置き換える項目数を表示して確認し、成功・失敗の結果を画面に表示します
- ダッシュボードをEnglish・日本語で表示したとき、一部の見出しやボタンが韓国語のまま残る問題を修正しました
- ダッシュボードを開いたままでもフォロー同期の状況がすぐに更新されます

## 安定性

- ワイルドカード（`*`）の多いフィルターパックを使うと、Xのタブが数秒間固まることがある問題を修正しました
- ワイルドカードのルールが複数行のプロフィールでも機能します
- 非表示の統計の一部が記録されない問題と、30日ではなく29日しか保存されない問題を修正しました
- フォローリストの保存が重なったときに一部が失われることがある問題を修正しました

## その他

- 標準フィルターリストを更新しました。ご協力いただいた方に感謝いたします
- FirefoxとEdgeにも最新バージョンが配布されるよう、配布プロセスを整備しました
