# Chrome 웹 스토어 등록정보 — 한국어

## 제품 세부정보

**이름:** Blue Badge Remover

**요약 (132자 이내):**

> X(트위터)의 파딱(유료 파란 뱃지) 트윗을 숨깁니다. 팔로우·화이트리스트·보호 키워드 계정은 그대로 보입니다.

## 상세 설명

Blue Badge Remover는 X 타임라인에서 유료 파란 뱃지(파딱) 계정의 트윗을 숨기고, 내가 믿는 사람과 관심사는 그대로 보여줍니다.

주요 기능:

- 유료 파란 뱃지만 감지합니다. 금색(기관)·회색(정부) 인증은 숨기지 않습니다.
- 팔로우한 계정은 자동으로 감지해 숨기지 않고, 팔로잉 페이지에서 전체 목록을 한 번에 가져올 수 있습니다.
- 화이트리스트에 여러 계정을 한 번에 추가하고, 접힌 트윗을 펼친 뒤 바로 예외로 등록할 수 있습니다.
- 내장·커스텀·가져온 필터 팩 키워드로 원하는 파딱 트윗만 골라 숨길 수 있습니다.
- 아이디·이름·프로필 소개에 좋아하는 사람, 장르, 커뮤니티가 들어간 계정은 보호 키워드로 계속 보이게 합니다.
- 프로필 정보를 브라우저 안에서만 사용해, 새로 만들어진 고확산 파딱 계정을 골라 숨길 수 있습니다 (선택).
- 리트윗과 인용 트윗을 따로 처리하고, 타임라인·답글·검색·북마크·리스트에서 동작합니다.
- 화이트리스트·커스텀 필터·보호 키워드를 검증된 JSON으로 내보내고 가져옵니다.
- 설정과 통계는 브라우저에만 저장합니다. 분석 도구, 외부 서버, 인증 토큰 저장이 없습니다.
- 한국어·영어·일본어를 지원하며 Chrome, Edge, Firefox, Android용 Firefox에서 동작합니다.

이 확장 프로그램은 브라우저에 보이는 화면만 바꿉니다. X에 글을 쓰거나, 좋아요·팔로우를 하거나, 콘텐츠를 수정하지 않습니다.

소스 코드와 문의: https://github.com/fotoner/blue-badge-remover
