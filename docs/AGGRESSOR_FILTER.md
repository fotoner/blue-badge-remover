# 신규 고확산 계정 필터 설계

## 목적

키워드 선별 모드에서 키워드가 아직 축적되지 않은 신규 고확산 파딱 계정을 보조적으로 선별한다. 이 기능은 계정을 “악성”으로 단정하지 않고, 사용자가 명시적으로 켠 경우에만 추가 후보를 숨긴다.

## 판정

다음 조건을 모두 만족할 때만 매칭한다.

- 계정 생성 후 183일 이내
- 팔로워 1,000명 이상
- `팔로잉 수 / 팔로워 수`가 0.1 이하

키워드 필터가 켜진 선별 모드에서 키워드 매칭과 OR로 적용한다. 팔로우, 수동 화이트리스트, 보호 키워드, 본인·예외 리포스터 규칙은 이 판정보다 우선한다.

## 보수적 폴백

X API 응답에 생성일·팔로워·팔로잉 중 하나라도 없거나 타입이 잘못되면 매칭하지 않는다. 임계값은 현재 고정값이며 원격 데이터 전송이나 추가 권한은 사용하지 않는다.

## 한계

이 휴리스틱은 어그로 여부를 직접 측정하지 않는다. 신규 유명인이나 공식 프로젝트도 조건에 들어올 수 있으므로 기본값은 꺼짐이며, 보호 키워드와 화이트리스트를 우선 적용한다.
